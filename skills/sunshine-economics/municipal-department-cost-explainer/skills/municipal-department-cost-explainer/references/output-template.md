# Output template

## Scope
Municipality, department, fiscal dates, budget status, currency/scale, source
snapshot, requested measure, budgetary basis (or unstated), exclusions.

## What the documents establish
Two or three sentences with headline, supported reconciliation and principal
limit. Distinguish appropriation from actual spending; label calculated figures.

## Evidence and reconciliation
| Item / fund | Amount | Treatment and reason | Source page/table/column |
|---|---:|---|---|
| Reported headline | | Starting figure, stated scope | |
| Adjustments | | Included/excluded/unresolved | |
| Documented total | | Only if supported; show equation | |

Give funding a separate table. Show a net formula only if supported. Preserve
reported figures even if discrepancies prevent reconciliation.

## What residents can conclude
Explain why figures differ. Identify missing schedules, possible overlap,
unverified extraction and unknown accounting details. State whether evidence
supports the requested scope. Explain relevant services only from sources.

## Questions to resolve
Up to three specific questions, each naming missing evidence and likely
schedule/staff role. No invented names.

## Sources and checks
Source IDs, publisher/title, URL/file, printed/PDF page, table/column, version.
State arithmetic, inclusion and coverage checks; distinguish AI checks from
external practitioner review. List unresolved discrepancies.

Draft explanation of documented budget figures, not an audit or a certification
of full cost. A municipal finance professional should review it before publication
or use in a budget decision.
