# Local context
Fill from the request and supplied evidence. Mark unknowns explicitly. This is
an intake template, not an executable configuration.

| Field | Establish |
|---|---|
| Municipality / jurisdiction | Official name and country |
| Department / boundary | Included divisions and excluded entities |
| Fiscal year | Beginning and ending dates |
| Budget status | Proposed/adopted/amended; date if available |
| Requested measure | Department operating appropriation by default |
| Currency / scale | Whole dollars, thousands, etc. |
| Budgetary basis | Source statement; unknown if unstated |
| Source inventory | Publisher, title, URL/file ID, version/access date |
| Headline table | Page, row, exact column, amount and coverage |
| Other schedules | Fund, staffing, allocations, internal services, transfers |
| Funding restrictions | Source evidence, if any |
| Audience / decision | Resident explanation, staff briefing, etc. |
| Limits | Missing schedules, unreadable pages, uncertain relationships |

Do not ask users for values already in the sources. Resolve department, year,
status and units before combining amounts. If unresolved, provide useful source
inventory and request the specific missing information.
