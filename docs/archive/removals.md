# Withdrawn skills

Skills that were listed and are no longer. One line each: what, when, and
whether it was the maintainer's decision or the registry's.

**No reason is recorded for a maintainer's withdrawal, because none is owed** —
see [CONTRIBUTING.md](../../CONTRIBUTING.md). A removal for a security reason
carries an advisory in `docs/advisories/` instead, and that is where the detail
goes; this file only says the listing existed.

The point is that somebody a year from now can tell a withdrawn skill from one
that never existed, and does not rebuild it by accident.

| Skill | Withdrawn | By | Notes |
|---|---|---|---|
| `civic-skills/search-the-exchange` | 2026-09-04 | Registry | Made redundant by the marketplace listings and the site's own filters, which cover finding a skill. What it uniquely carried — tier and scan status on every result — belongs in the listing metadata rather than in a skill |
| `civic-skills/submit-a-skill` | 2026-09-04 | Registry | Most agents can already write a skill; what none can do is say what this registry requires. Superseded by the idea of preparing an existing skill to meet the contract, not by a rewrite |
